# **App Name**: Covenant Link

## Core Features:

- Event Scheduler & Notifications: Create, edit, and view upcoming meetings, outings, and events. Monthly push/email reminders. comments per event.
- Interactive Bible & Group Notes: Embed a searchable, interactive Bible. Let users highlight, annotate, and write group-visible or private notes. Threaded discussions on specific verses or themes.
- Christian Couple Game Generator: AI tool generates fun, faith-based games (icebreakers, couple challenges, trivia). Filter by mood (fun, deep, spiritual, etc.).
- Couples Discussion Topic Generator: Generative AI tool suggests Weekly/monthly prompts with scripture references. Suggested questions for group discussion. Option for couple on duty to customize topics.
- Group Projects & Contributions Tracker: Add projects (e.g. “End-of-year food purchase”). Track monthly contributions per couple. View progress bars, deadlines, and reminders.
- Outing Spots in Cameroon: Compile Curated list of fun, romantic, and family-friendly places to visit. Location filtering, ratings, pictures, and Google Maps links.

## Style Guidelines:

- Primary Color: Deep Purple `#673AB7` – evokes spirituality & unity
- Accent Color: Soft Lavender `#D1C4E9` – warm, inviting highlights
- Background Color: Light Gray `#F5F5F5` – clean and minimal
- Clear sans-serif (e.g., Nunito or Lato); elegant headings
- Feather or Material Icons – minimal and relevant
- Clean modals for interactions
- Subtle transitions, collapsible sections
